## 加州住宅 IP 到底指什么，怎么一眼验证

加州住宅 IP 指由加州本地运营商（AT&T、Comcast、Spectrum、Frontier、Cox）分配给真实家庭或移动用户的地址。判断方法不复杂，把 IP 丢进 ARIN WHOIS、bgp.he.net 或 ipinfo.io 查归属：住宅 IP 显示的是「Private Customer – AT&T Internet Services」这类个人客户记录，机房 IP 显示的是 Vultr、AWS、DigitalOcean 之类的托管机构。

市面上叫「住宅 IP」的东西分三种，价格差得远，效果也差得远。

**动态旋转住宅代理**按流量（GB）计费，每次请求换一个 IP。做数据采集合适，养账号不合适，因为同一个账号今天在洛杉矶、明天在纽约，本身就是异常信号。

**静态住宅 IP（ISP 代理）** IP 固定，但底层可能是双 ISP 转发，也就是机房 IP 借住宅网络出去。第三方工具细查 ASN 和路由，能看出差异。

**真实家宽 VDS** 是服务商在本地公寓拉一条 AT&T 或 Frontier 的家庭宽带，再以 VPS 形式交付。IP 从源头就是住宅宽带，没有转发环节。

按业内整理的品质梯度排：机房原生 IP ＜ 单 ISP 住宅 IP ＜ 双 ISP 住宅 IP ＜ 真实家庭宽带 VDS，价格基本同向上升。

SixtyNet 的位置需要说清楚。它官网的住宅产品线挂在 AT&T Mobility 名下，套餐标识写作 att-moble-starter 这一类，说明 IP 来自 AT&T 的移动网络侧，不是公寓里的固定光纤。2025 年 10 月有第三方测评站对其 Cox 线路做过检测，ipinfo 判定为双 ISP 属性，多个数据库一致给出「原生美国 IP、家宽属性、风险评分低、流媒体解锁正常」的结论。这属于上面梯度里的第二到第三档，也是它能把价格压到 $25/月的原因。真要买最贵那档自建公寓光纤，预算得按 35 美元往上准备。

## 80 和 443 端口为什么关闭，影响哪些用法

SixtyNet 在住宅系列的每一个套餐下面都写了一行提示：因为 IP 风控原因，住宅 IP 产品不开放 80 和 443 端口。

这句话的实际含义是，这台机器不能对外提供 HTTP 或 HTTPS 服务。由此排除的用法包括：建站、挂 Web 控制面板、做落地页、跑需要公网 443 回调的 webhook、把独立站或 Shopify 应用的回调地址指向这台机器。

不受影响的用法：SSH（22）、远程桌面、SOCKS5 自定义端口、指纹浏览器、后台登录、视频上传下载、流媒体播放。也就是说，TikTok 运营、亚马逊和 eBay 卖家后台、支付平台管理、账号矩阵这些主流场景，端口关闭基本无感。

对住宅 IP 来说这其实是合理设计。家宽和移动网络的入站端口本来就是关闭的，一旦开放 80/443，这个 IP 在扫描器眼里立刻变成「住宅地址上跑着服务器」，住宅属性就白买了。SixtyNet 把这条写进产品页，算是提前把话说清楚。

需要建站的话，它官网另有一条 LAX 产品线，机房 IP 加 DDoS 防护，80/443 正常开放，$20/月起。两条线各干各的事，别混着买。

## 常见问题

**能注册 Gmail、Google Voice 吗？**

没有公开的 SixtyNet 加 Gmail 注册实测记录，我不编。能核验的是 IP 层面：第三方对 Cox 线路的检测显示 ipinfo 判定为双 ISP、原生美国 IP、家宽属性、风险评分低。IP 属性是必要条件，不是充分条件，Gmail 是否弹手机验证还跟浏览器指纹、号码历史、注册节奏有关。

**TikTok 会不会触发风控？**

同理，没有公开实测数据。住宅属性降低的是 IP 层被识别为代理的概率，账号能不能稳住还取决于设备指纹、行为模式和内容本身。**端口关闭这件事反而说明 SixtyNet 在刻意维护 IP 的住宅特征，不给扫描器留把柄。**

**国内延迟多少？**

官方屏蔽了 ICMP，第三方测不出 ping 值，任何给出精确毫秒数的说法都不可信。路由层面可查：2025 年 10 月的测评显示电信去程走 CN2 直连洛杉矶，联通直连洛杉矶后接 GTT，移动直连洛杉矶；回程电信和移动走 CN2，联通走 AS10099 加 AS9929。这个路由组合对国内用户属于友好的一档。真要稳定，还是自备中转节点把流量先送到美国境内。

**IP 能换吗？**

官网套餐页没有写换 IP 政策。这类产品通常按付费服务处理，需要开工单确认。

**$25 和 $165 的套餐，IP 质量一样吗？**

一样。四个 Residential 套餐的差别只在 CPU、内存、硬盘和月流量，IP 属性是同一套。这就是为什么单人运营买 STARTER 就够，多花的钱买的是算力，不是更干净的 IP。
